# VICEBLOCK 3D

Nova City SOUTH DOCKS. Guest first. Wallet is sign-only identity. No contract address.

Browser third-person **line-slinger** slice. Babylon.js. ANSEM / ORANGIE / CUPSEY in original masked kits (no borrowed comic marks). Play at the deployed Vercel URL or `npm run dev`.

This is an original dusk-vice web-slinger, not a Marvel / Sony title. The hero is a masked liner on the South Docks: hold to attach, pendulum swing, release, zip, crawl a wall, leap back into a line.

## Real
- Pendulum swing is the toy: hold F / SALIN to attach, steer the arc, release and reattach, E / ZIP to a point, air steer, rooftop walk, wall crawl
- Dense enough South Docks to swing for a few minutes: towers, walkups, strip, crane, lamps, street cables
- Short guest loop: first line → dock crane → stun three → lose heat high → free roam
- Combat is web-stun, yank, melee, air takedown. Heat is local stars; swinging high drops it
- Desktop: mouse look without pointer lock, WASD, hold F SALIN, E ZIP, click ATEŞ, Space jump. Phone: left stick, right look, SALIN / ZIP / ATEŞ
- Title → character select → South Docks
- Radio + web / whoosh / impact if `public/audio` files are present (generated MP3s)

## Unfinished / not faked
- Procedural meshes, not film-quality character or city assets
- A browser slice, not an open-world spider sim
- No multiplayer, party, online counts
- No NFT shop, no token, no contract address, no server validation
- No 8 districts, weather cycle, crews, seasons, or admin dashboard
- Cars and interiors still exist as set dressing from the older docks build; driving is not the loop
