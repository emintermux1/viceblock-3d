# VICEBLOCK 3D

Nova City SOUTH DOCKS. Guest first. Wallet is sign-only identity. No contract address.

Browser third-person **line-slinger** slice. Babylon.js. ANSEM / ORANGIE / CUPSEY in original masked web-suits (no borrowed comic marks). Play at the deployed Vercel URL or `npm run dev`.

This is an original dusk-vice web-slinger, not a Marvel / Sony title. The hero is a masked liner on the South Docks: hold to attach, pendulum swing, release, zip, climb a wall, vault a roof, walk it, then leap back into a line.

## Real
- Pendulum swing is the toy: hold F / SALIN to attach, steer the arc, release and reattach, E / ZIP to a point, air steer
- Rooftops are walkable. If you land on one you stand, WASD / stick walk, then leap or swing off. Embedded collisions push you out or snap you onto the roof
- Wall climb: approach a facade and hold toward it or C / TIRMAN, climb up, vault onto the roof
- Street lamps, cables, crane, and building ledges as attach points
- Short guest loop: first line → dock crane → stun three → lose heat high → free roam
- Cars work again: near a car, F / BİN to get in and drive. BİN is a prompt, not a permanent chrome letter
- Combat is web-stun, yank, melee, air takedown. Heat is local stars; swinging high drops it
- Desktop: mouse look without pointer lock. Phone: left stick, right look, SALIN / ZIP / ATEŞ, plus TIRMAN and BİN when they apply
- Title → character select → South Docks
- Radio + web / whoosh / impact if `public/audio` files are present (generated MP3s)

## Unfinished / not faked
- Procedural meshes, not film-quality character or city assets
- A browser slice, not an open-world spider sim
- No multiplayer, party, online counts
- No NFT shop, no token, no contract address, no server validation
- No 8 districts, weather cycle, crews, seasons, or admin dashboard
