# VICEBLOCK 3D

Nova City SOUTH DOCKS. Guest first. Wallet is sign-only identity. No contract address.

Browser third-person dusk-vice slice. Babylon.js. ANSEM / ORANGIE / CUPSEY. Play at the deployed Vercel URL or `npm run dev`.

## Real
- South Docks art pass: brick/storefront/tower/warehouse facades, sunset sky, tiled pavement, dock planks, crane, containers, pilings, water, lamps, palms, strip neon
- Heroes, peds, cops, and cars with readable silhouettes, lights, and walk/drive motion
- Missions you can finish in one sitting: jack a ride → Maya garage → Nova Mart register → cool off. Cash, heat, garage repair
- Local systems: hotwire, witnesses, search, short jail, interiors, Rico fence, component damage, localStorage
- Desktop: hold left or right mouse to look (no pointer lock required), Q/E, WASD, click shoot. Pause can invert look. Phone: left stick + right-drag look
- Radio + gun / engine / siren / crash / reload / melee if `public/audio` files are present (they ship as generated MP3s)

## Unfinished / not faked
- Procedural meshes, not film-quality character or city assets
- No multiplayer, party, online counts
- No NFT shop, no token, no contract address, no server validation
- No 8 districts, weather cycle, crews, seasons, or admin dashboard
- Heat is local wanted stars on this pier, not a living city sim
